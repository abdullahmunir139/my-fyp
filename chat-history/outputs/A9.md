# A9 — Graphify installation guide for Windows

## 1. Make the guide for installing Graphify in Windows OS

The requested guide has been compiled into the guides module:

**`guides/Q9A9_graphify-windows-install-guide.md`**

It is a standalone Windows 10/11 walkthrough covering:

1. **Prerequisites** — Python 3.10+, uv (recommended), Git; the critical
   *"Add python.exe to PATH"* installer checkbox.
2. **Install Graphify** — `uv tool install graphifyy` (recommended, isolated) or
   `python -m pip install graphifyy`; optional `graphifyy[gemini]` extra.
   Emphasis on the package spelling: PyPI package **`graphifyy`** (double y) vs
   the CLI command **`graphify`** (single y).
3. **Verify** — `graphify --version`, plus a step-by-step fix for
   *"graphify is not recognized"* (PATH / Scripts folder for uv and pip).
4. **Build the graph for this repo** — `graphify update .` from the repo root
   (AST-only, no API key), then `graphify query` / `path` / `explain`.
5. **Windows-specific notes** — PowerShell execution policy, long-path registry
   fix, Windows Terminal recommendation, and the no-API-key clarification.
6. **Command reference** and a **troubleshooting table**.
