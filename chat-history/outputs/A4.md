### 5.2 NPK sequence — the SFRI algorithm

```mermaid
sequenceDiagram
  autonumber
  participant FE as NPK page
  participant BE as POST /api/soil/recommend
  participant SF as sfri.service
  participant SB as sfri_bands
  FE->>FE: farmer enters N, P, K, pH + acres + soil type
  FE->>BE: n, p, k, ph, soilType, acres
  BE->>SF: rankTest(ppm) x3
  SF->>SB: findOne soilType + nutrient
  SB-->>SF: band idealLow, idealHigh, cropRequirement
  SF->>SF: nutrientNeeded = cropReq - soilTest
  SF->>SF: bags = ceil(kg / gradeFraction / 50)
  SF-->>BE: deficits, ureaBags, dapBags, mopBags, cost
  BE-->>FE: result
  FE-->>FE: RadarChart + bag table
```
